# Project boundary

`finance-quant` owns the quantitative research/trading laboratory.

External integrations may include:
- FOSSIL for durable research evidence, provenance, reviewed knowledge, and lineage references;
- Cortex for bounded orchestration/task execution;
- MLflow for experiment/run artifacts;
- Qlib for predictive research/training;
- QuantConnect LEAN for execution/backtest/paper/live semantics.

None of those external systems becomes project ownership merely because this repository integrates with it.
